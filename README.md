# Production-Ready RAG Chatbot

A production-ready Retrieval-Augmented Generation (RAG) chatbot built with:

- Google Gemini
- LangChain
- Chroma
- FastAPI
- Docker

## Features

- PDF ingestion
- Semantic search
- Retrieval-Augmented Generation
- Source citations
- Conversation memory
- Streaming responses
- Docker deployment

## Tech Stack

- Python
- Google Gemini
- LangChain
- ChromaDB
- FastAPI
